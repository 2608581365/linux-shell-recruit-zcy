# Task 08 Answer

请在这里简短回答：为什么 Shell 中 `$var` 和 `"$var"` 有时会产生不同的结果？

1. **不加引号 `$var`**：
   Shell 会自动按空格、制表符把变量值拆成好几段。
   如果文件名里本身带空格（比如 `my file.txt`），不加引号就会被切成 `my` 和 `file.txt` 两半，程序根本找不到这个文件。

2. **加引号 `"$var"`**：
   加了双引号，Shell 就会把整个变量值当成**一个整体**传给程序，里面就算有空格也不会被拆开。所以处理文件名时，必须加双引号。

同理，处理命令行参数时，要用 `"$@"` 而不是 `$@`，这样每个参数（尤其是带空格的）才能被完整保留。
