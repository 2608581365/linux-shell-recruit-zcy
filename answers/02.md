# Task 02 Answer

请在这里回答题目中的两个问题。
## 问题 1：为什么 `./tools/recruit-info` 能运行，而直接输入 `recruit-info` 可能找不到？

1. **使用 `./tools/recruit-info` 能运行的原因：**
   `./tools`指令提供了相对路径，告诉了Shell具体的地址。Shell 找到了该文件，并且该文件具有可执行权限，因此可以运行。

2. **直接输入 `recruit-info` 找不到的原因：**
   直接输入 `recruit-info` 时，Shell 会去环境变量 `PATH` 所包含的目录中查找这个程序。因为 `tools` 这个文件夹并不在 `PATH` 列表中，所以 Shell 遍历完所有 `PATH` 目录后找不到该程序，就会报 `command not found`。

## 问题 2：Shell 输入 `ls` 时如何找到程序？

当输入 `ls` 命令时，Shell 的查找过程如下：

1. Shell 会读取环境变量 `PATH` 的值，获取一个包含多个目录的列表。
2. Shell 会按照 `PATH` 中目录的顺序，依次进入每一个目录，查找是否存在名为 `ls` 的可执行文件。
3. 一旦在某个目录中找到 `ls` 文件，Shell 就会停止查找，并执行该文件。
4. `ls`是自带的系统程序，所以Shell可以在PATH直接找到并执行。
